  WHAT WAS FIXED
═══════════════════════════════════════════════════════════════

Problem:
  Ngrok was intercepting API calls with browser warning page
  → Caused 400 Bad Request errors
  → Chatbot couldn't send messages

Solution:
  Added header to all API calls:
  ngrok-skip-browser-warning: true

This tells ngrok:
  "Skip warning page, forward directly to server"
